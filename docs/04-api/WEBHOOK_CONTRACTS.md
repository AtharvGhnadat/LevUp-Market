## 1. Cashfree Webhook Contract

### 1.1 Ingestion Endpoint

- **URL**: `POST /api/webhooks/cashfree`
- **Headers**:
  - `x-webhook-signature`: Base64 HMAC-SHA256 signature generated by Cashfree
  - `x-webhook-timestamp`: Epoch timestamp in milliseconds
  - `Content-Type`: `application/json`

### 1.2 Verification Algorithm

```typescript
import crypto from "node:crypto";

export function verifyCashfreeSignature(
  rawBody: string,
  timestamp: string,
  signature: string,
  secret: string,
): boolean {
  const data = timestamp + rawBody;
  const expectedSignature = crypto.createHmac("sha256", secret).update(data).digest("base64");

  return crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expectedSignature));
}
```

## 2. Idempotency & Failure Handling

1. **Storage of Raw Payload**: The complete raw JSON payload is preserved in `payment_events`.
2. **Deduplication Key**: The combination of `event_time` and `data.payment.cf_payment_id` is unique. If a record with this key already exists:
   - Log an `info` event indicating duplicate webhook received.
   - Return HTTP `200 OK` immediately without repeating fulfillment or email operations.
3. **Out-of-Order Webhooks**: If a `PAYMENT_FAILED_WEBHOOK` arrives after a `PAYMENT_SUCCESS_WEBHOOK`, the `SUCCESS` status is terminal and cannot be downgraded.
