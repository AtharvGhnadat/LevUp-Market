## 7. Remaining blockers and recommended fixes

1. Keep the payment endpoints disabled across environments. Confirm credential revocation and rotation through the merchant dashboard, then verify the explicit off switch using synthetic credentials.
2. Before accepting payments, fix server-owned cart pricing, checkout access, safe response mapping, verified callbacks, durable idempotency and transactional fulfillment.
3. Resolve the reproducible Supabase import failure, restrict financial and audit writes, and run role tests against a disposable Supabase database. Deployed grants, Data API exposure, and storage policies still require verification.
4. Resolve Windows formatting policy and Stage E CI. Run the quality gates with the pinned toolchain and extend CI coverage to stack bases and Playwright. Check branch protection in GitHub settings.
5. Fix draft retention and prefill replacement, manage focus across requisition phases, and keep file staging and export labeled accurately.
6. Correct release documents and preserve the merge dependency order. Confirm external deployment triggers and obtain security clearance before any historical tag.
